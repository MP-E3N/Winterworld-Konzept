Steuerung

W / SMaschinentelegraf eine Stellung voraus / zurück (Stopp, dann rückwärts). Die Maschine hält das Tempo der Stellung selbst. Auch per Klick auf den Telegrafen.
A / Dlenken (wirkt erst bei Fahrt)
LScheinwerfer an/aus (auch Klick auf die Öllampe in der Anzeige)
Linksklickauf eine Fundstelle oder einen abgeworfenen Haufen: Trupp bergen lassen (nur im Stand, Telegraf auf Stopp, in Reichweite). Der Ring zeigt, ob es geht. Nochmal klicken: zurückholen. Auf den eigenen Koloss: Lager öffnen.
Q / EFeuer runter / rauf. Es füllt den Dampfvorrat; wer schneller fährt, als das Feuer nachliefert, sieht den Druck fallen — dann langsamer fahren oder stärker heizen.
BBrennstoff wählen: Kohle, Holz (brennt doppelt so schnell), Öl (halb so schnell). Auch per Klick auf den Wahlschalter. Ist er alle, geht das Feuer aus.
OHeizung an/aus (auch Klick auf den Ofen) — wärmt, kostet Brennstoff
ILager: Brennstofflager 100 t, Warenlager 60 t; abwerfen (1 t, Umschalt = alles), Holz umlagern

Liegenbleiben: Ist die ganze Crew tot, oder ist kein Brennstoff mehr an Bord und der Kessel bleibt 2 min kalt, bleibt der Koloss liegen. Das Wrack bleibt mit seiner Ladung in der Welt, du startest neu.

Testgelände: Geradeaus im Norden liegt ein zugefrorener See (rutschig, schnell, schlechte Bremsen), im Westen eine Pulverschnee-Wehe (halbes Tempo). Rechts neben dem Start liegt eine Kohlehalde, dahinter eine Ruine, im Südosten ein Vorratslager, im Nordwesten Ölfässer.
